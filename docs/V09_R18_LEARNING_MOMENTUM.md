# V0.9.0 R18 · Learning Momentum

Adds a compact visual-reward layer to Learn without changing the core page flow.

- XP badge and learning streak
- Today completion ring
- Monthly completion ring
- Listen / Speak / Read / Write mastery bars
- Evidence-aware mastery labels
- Completed task rows use a clearer success treatment
- Compact Today view no longer repeats the streak summary

All progress is derived from existing D1 learning, XP and mastery records. No schema migration is required.
