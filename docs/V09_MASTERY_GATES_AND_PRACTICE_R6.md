# English Mastery V0.9.0 R6

## Writing mastery gate
A Writing prompt is not complete merely because it was submitted. Every Save & review creates a historical version. The AI review score is calculated from the writing rubric. A score below 60% keeps the current prompt locked for revision. A score of 60% or above marks the submission Passed, completes the matching daily Writing task and unlocks the next unpublished/unpassed prompt.

## Reading mastery gate
Learn Reading and fixed Paper 2 Reading practice are sequential. The current question must be correct before the Next question control appears. Incorrect answers remain retryable. Server-side progress counts distinct correctly answered questions, not merely attempted questions. The Reading daily task can complete only when every question in the assigned reading/set has at least one correct attempt.

## Daily game reward
The game reward is no longer granted per completed subtask. Exactly one reward can be minted for a Singapore calendar day, and only when that day's Listen, Speak, Read and Write learning tasks are all `done`. Vocabulary and Science remain separate and do not mint additional rewards.

## Practice layout
The specialised Practice cards use two columns on desktop and one column on narrower screens. Card metadata is in normal document flow instead of absolutely positioned at the card bottom, eliminating overlaps after the 17px minimum-font change. Question cards, options, setup controls and helper text use explicit gaps, safe wrapping and responsive widths.
