# V0.9.0 R17 · Visual System Refresh

Layout is intentionally unchanged. This release refreshes the visual language using a Duolingo-inspired approach: bold but controlled learning colors, soft backgrounds, modular cards, clearer progress bars and status feedback.

## Palette
- Learning / primary: blue
- Pass / completion: green
- Streak / attention: amber
- AI / advanced accents: violet
- Error / fail: red

The palette uses light tints for large surfaces and reserves saturated colors for small high-value elements, reducing eye strain.

## Charts and progress
Progress bars use blue gradients, completed calendar days use green, partial days use blue, and stat cards rotate green/blue/amber/violet top accents.

## Accessibility
Focus rings, disabled states, text contrast and restrained background saturation are preserved.
