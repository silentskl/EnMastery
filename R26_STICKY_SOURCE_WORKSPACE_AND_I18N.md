# V0.9.0 R26 — Sticky Source Workspace + bilingual operations UI

- `Source & content workspace` is now a sticky toolbar below the global top bar on platform and tenant admin pages.
- The active Source Studio tab remains visible while scrolling long source, discovery, queue and library panels.
- Added persistent operation-console UI language setting: English / Simplified Chinese.
- Language switch is available in the platform/tenant top bar and is stored in browser localStorage (`em-ui-language`).
- Platform and tenant navigation, Source Studio toolbar/tabs and common operation labels are translated client-side without changing curriculum/content language.
- Dynamic lesson titles, source names, student names and generated learning content are intentionally not auto-translated.
