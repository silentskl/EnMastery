# English Mastery v1.0.2 Hotfix 12.1

## Immutable Daily Learning Mission

- Once a learner/date has been materialised into `learning_tasks`, the persisted Daily Learning Mission is now **locked for that date**.
- Application/planner version changes no longer delete or reselect persisted `todo` / `skipped` cards.
- Reopening Learn, refreshing the browser, deploying a new release, or changing Tenant Admin Learning Settings does not replace an already-generated daily mission.
- Course/stage changes likewise apply only to future dates that have not yet been materialised; existing daily cards keep their persisted content IDs.
- Writing PASS no longer deletes already-generated future Writing cards.

## Writing PASS recovery

- Fixes the case where Writing had already passed but Today still showed a newly-regenerated Writing card as `todo` after an upgrade.
- The Today plan endpoint performs a targeted same-day recovery check before returning the mission.
- When an upgrade-created replacement Writing card is detected after a valid same-day PASS, the persisted Writing assignment is restored to the passed prompt and completed idempotently.
- The recovery is deliberately conservative: an unrelated Writing PASS is not adopted when there is no evidence that a Daily Mission existed before that PASS.

## Configuration behaviour

- Admin policy changes are **prospective**: they affect only learner dates that have not yet generated their Daily Mission.
- The same rule applies to content stage changes. Existing Today/future materialised cards are never silently regenerated by those settings changes.

## Database

- Schema remains at **57 migrations / 107 application tables / 17 maintenance triggers**.
