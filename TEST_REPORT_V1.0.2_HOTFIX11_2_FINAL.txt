English Mastery v1.0.2 Hotfix 11.2 - Final Validation Report
Date: 2026-09-01

ISSUES FIXED
1. Vocabulary import could fail when ModelBridge returned almost-valid JSON, for example a trailing comma:
   SyntaxError: Expected double-quoted property name in JSON ...
2. Reading import used the same direct JSON.parse pattern and could fail for the same reason.
3. A partially completed vocabulary import needed to be safely runnable again without duplicate terms.

IMPLEMENTATION
- Added lib/ai/model-json.ts as the shared resilient model JSON parser.
- JSON parsing pipeline:
  1) extract fenced/prose-wrapped JSON;
  2) strict parse;
  3) conservative local syntax repair for trailing commas/comments/literal control characters;
  4) strict parse again;
  5) if still invalid, one ModelBridge JSON-syntax repair request;
  6) validate repaired root type and then run domain validation.
- Final JSON errors include initial parse error, repair parse error and a bounded source excerpt.
- Vocabulary batch enrichment falls back to individual term enrichment if the repaired batch still cannot be used.
- Individual failures are logged without discarding successfully imported terms from the same chunk.
- Vocabulary import is idempotent per Tenant word book:
  * source items normalized by trim + whitespace collapse + case-insensitive key;
  * duplicates inside TXT/CSV/editor input are merged before queueing;
  * existing target-book normalized terms are checked before AI enrichment;
  * already imported terms therefore do not consume another enrichment request on rerun;
  * collection insertion checks normalized_text, not just vocabulary_id, preventing legacy-ID duplicates;
  * new synonym annotations merge into an existing term instead of creating another term;
  * result includes duplicates as a subset of skipped.
- Work Queue vocabulary summaries now show duplicate counts.
