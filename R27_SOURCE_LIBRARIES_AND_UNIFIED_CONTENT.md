# R27 — source-first domain libraries and unified content moderation

- Reading now shows its source/discovery workflow and a dedicated Reading lesson library, matching the Listening source + lesson-library model.
- Speaking and Writing now expose category-filtered reference-source catalogues before their content creation/library tools. Platform Admin can add additional sources; Tenant Admin sees platform-approved sources read-only.
- Cloze and Question Bank are independent workspace tabs. Cloze is locked to cloze sources/batches/items; Question Bank contains Oral, Reading Comprehension and Writing bank items.
- Question-bank library views now include approved/published items as well as generation/review/error states, rather than only the active draft queue.
- Content Library is a true cross-domain moderation surface combining Reading, Listening, Speaking, Writing, Cloze and Question Bank content. It supports type/status filters, bulk selection, publish and take-offline actions.
- Tenant bulk moderation is ownership-safe: global platform content may be visible through domain APIs but only tenant-owned rows can be changed.
