English Mastery V1.0.2 Hotfix 5.1 - D1 Migration Compatibility Test Report
Date: 2026-08-31

Issue reproduced
----------------
Remote Cloudflare D1 migration apply failed while 0043/0044 were pending:
  too many terms in compound SELECT: SQLITE_ERROR [code: 7500]

Root cause
----------
0043 and 0044 used seven-term UNION ALL chains to seed school stages and practice activities.
Cloudflare D1 remote migration execution may enforce a low SQLITE_LIMIT_COMPOUND_SELECT.

Fix
---
- 0043 now seeds stages with WITH levels(level) AS (VALUES ...).
- 0044 now seeds stages and activities with VALUES CTEs.
- No executable UNION / UNION ALL remains in migrations 0043 or 0044.
- Migration numbers and filenames remain 0043/0044 so a failed remote migration can be retried normally.
- Added .gitattributes to force LF line endings for migration SQL.
- Added scripts/test_d1_migrations.py and npm script test:d1-migrations.
- npm run check:release now includes the D1 migration compatibility regression.

Remote retry procedure
----------------------
1. Replace the project with this Hotfix 5.1 package (or replace only the migration patch files).
2. Check pending migrations:
     npx wrangler d1 migrations list english-mastery --remote
3. Confirm 0043 and 0044 are still pending.
4. Apply:
     npm run db:migrate:remote
   or:
     npx wrangler d1 migrations apply english-mastery --remote
5. Run:
     npm run test:d1-migrations
     npm run test:hotfix5

Cloudflare documents that a failed D1 migration is rolled back and is not recorded as applied, while earlier successful migrations remain applied. Therefore no manual cleanup should normally be required after the reported failure.
