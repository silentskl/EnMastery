English Mastery v1.0.2 Hotfix 10 - Final Validation Report
Date: 2026-09-01

PURPOSE
Move vocabulary word-book bulk import to Tenant Admin and make it a persistent background workflow in the existing Task Queue. Student learning pages must not expose bulk import or word-book administration. Multiple import jobs must execute in FIFO order with only one job running at a time.

IMPLEMENTED
1. Tenant Admin Word Books
   - Create an empty tenant-managed custom word book.
   - Create a word book and queue TXT/CSV/pasted-text import.
   - Queue TXT/CSV/pasted-text import into an existing tenant word book.
   - Server-side parsing, normalization, case-insensitive deduplication and synonym merging.
   - Import payload limit: 2 MB; up to 2,000 unique terms per job.

2. Persistent background import
   - Imports are stored as generation_jobs with jobType=vocabulary_import before processing.
   - Existing TASK_QUEUE/task-runner is reused; no browser-owned processing loop.
   - Processing is checkpointed in chunks of up to 20 terms.
   - Cursor and counters are persisted in the job request/result so refresh, navigation, logout or worker reinvocation does not lose progress.
   - Work Queue shows target word book and processed/total/added/updated/skipped/failed counts.

3. FIFO / single concurrency
   - Existing persisted-job selection is ORDER BY COALESCE(enqueued_at,created_at) ASC, rowid ASC.
   - task-runner max_batch_size remains 1.
   - task-runner max_concurrency remains 1.
   - A partially completed vocabulary import retains its original enqueued_at when re-queued, so later import jobs cannot overtake it.
   - Failed items are recorded without aborting the rest of the job; a terminally failed job does not block the next queued job.

4. Student permissions / lesson workflow
   - Student bulk import endpoints return 403 and the Student UI no longer exposes TXT/CSV/editor import, custom word-book creation or deletion.
   - Tenant-managed custom word books are visible to students in the same tenant.
   - Students can continue to save an unknown word/phrase selected in a lesson into an available tenant custom word book.
   - Tenant Admin Learning/Practice policies can select published system books or tenant-managed custom books.

5. Database
   - Added migration 0050_v102_hotfix10_tenant_vocabulary_import.sql.
   - vocabulary_collections now supports tenant ownership and tenant lookup indexing.
